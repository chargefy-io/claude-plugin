# Chargefy para Claude Code

Marketplace oficial do plugin da [Chargefy](https://chargefy.io) para o Claude
Code e o Cowork.

```bash
claude plugin marketplace add chargefy-io/claude-plugin
```

```bash
claude plugin install chargefy@chargefy
```

O que vem no plugin, como autenticar e o que cada skill cobre está em
[plugins/chargefy/README.md](plugins/chargefy/README.md).

## Sobre este repositório

O conteúdo é **gerado** a partir do monorepo da Chargefy, onde as tabelas de
cartões de sandbox e de códigos de recusa saem do mesmo código que roda em
produção. Por isso, pull request aqui não é o caminho: abra uma issue ou fale
com suporte@chargefy.io e a correção volta pela origem.

Documentação: [docs.chargefy.io](https://docs.chargefy.io/mcp/installation)
